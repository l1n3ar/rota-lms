## Overview

ROTA is a free, open‑source LMS designed for developers and educators who want a fast, modern, and self‑hosted platform for managing courses, lessons, and users. Built with Next.js and Django REST Framework, it offers a clean architecture that’s easy to extend and integrate.

## Features

- **Next.js frontend** — fast, responsive, SEO‑friendly  
- **DRF backend** — clean, scalable REST APIs  
- **Self‑hosted** — deploy on your own infrastructure  
- **Customizable** — extend models, endpoints, and UI  

## Tech Stack

- **Frontend:** Next.js, React  
- **Backend:** Django, Django REST Framework  
- **Python tooling:** uv  
- **Database:** PostgreSQL
